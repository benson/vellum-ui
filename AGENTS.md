# Agent Workflow

Vellum UI is the upstream design system for Benson Perry apps.

## Naming

- Use `Vellum UI` for the system name.
- Use `vellum-ui` for the repo, URL path, generated asset folder, and local project folder.
- Use `@benson/vellum-ui` for the package name.
- Use `PoolBuilder` or `poolbuilder`; do not preserve dictated spellings like "Pool Builder".

## Editing

- Edit source in `src/`.
- Do not hand-edit `dist/`; it is generated by `npm run build`.
- Canonical CSS package tokens use `--vui-*`. The `--bui-*` alias layer is gone; unprefixed aliases (`--color-*` etc.) remain until vellum's internal CSS migrates off them.

## Verification

Run:

```powershell
npm run check
```

For visual changes, render `dist/design-system.html` locally and verify the relevant component states.

## Release

Merging to `main` triggers `.github/workflows/release-consumers.yml`.

The workflow opens and merges consumer PRs after checks pass. It needs the `BENSON_RELEASE_TOKEN` repository secret. If that secret is missing, leave the workflow code intact and report that cross-repo release automation is installed but inactive until the secret is configured.

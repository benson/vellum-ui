# Vellum UI

Vellum is the shared layer of CSS tokens, browser-native primitives, and small
ESM interaction helpers used across Benson Perry apps.

This Storybook renders the real package source. Use the toolbar to switch
themes, open a component's controls to explore its supported states, and use
the interactions panel to inspect behavioral checks.

The repository remains the source of truth. Stories document reproducible
states; they do not create a parallel component implementation.

# Vellum UI

Vellum is the shared layer of CSS tokens, browser-native primitives, and small
ESM interaction helpers used across Benson Perry apps.

This Storybook renders the real package source. Use the toolbar to switch
light/dark mode and experimental palettes, open a component's controls to
explore its supported states, and use the interactions panel to inspect
behavioral checks.

## Two layers

- **Vellum owns foundations and reusable primitives:** tokens, controls,
  feedback, overlays, and shared interaction contracts.
- **Applications own compositions:** product-specific rows, toolbars, editors,
  and workflows should consume Vellum without forcing their domain language
  into this package.

Start a broad visual pass in **Foundations / Theme playground**. Use the palette
toolbar to carry a direction across every story, then use each component's
**Deep dive** stories for state matrices, content stress, keyboard paths, and
responsive checks.

The repository remains the source of truth. Stories document reproducible
states; they do not create a parallel component implementation.
